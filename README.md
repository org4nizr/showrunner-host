# ShowRunner Host

ShowRunner Host is the desktop host app for ShowRunner. It runs on the streamer's computer and is the
heart of the show: it plays the set with a sample-accurate audio clock, drives the lights rig in sync,
and (later) brings in guests and feeds the program into OBS. Viewers and guests connect through the
ShowRunner site.

## Download

Installers for Windows, macOS and Linux will be published under
[Releases](../../releases) (coming soon). Installed apps update themselves from there.

## Sign-in

Sign in with Google in your system browser. The app keeps your session on this computer, encrypted by
the operating system, and works offline once signed in.

## Privacy

The app talks only to ShowRunner, Google sign-in and GitHub Releases (for updates), plus lights on your local network. It has no
analytics or telemetry.

This repository holds this README and the release installers only.
